Order Management System (OMS)

User Guide & Execution Instructions

1. Project Overview

This project is a Web-Based Order Management System developed to manage orders, inventory, invoices, and payments efficiently.

2. Folder Structure

OMS_Project/
│
├── frontend/        (Angular Build)
├── backend/         (Spring Boot JAR)
├── supported-documents/
└── README.html

3. System Requirements

  • Java 17 or above installed
  • Node.js (optional for frontend server)
  • Modern browser (Chrome recommended)

4. Backend Setup (Spring Boot)

Steps to run backend:

cd backend
java -jar OMS_backend-0.0.1-SNAPSHOT.jar

Backend will start at:

http://localhost:8080

5. Environment Variables Setup (Backend)

Before running the backend, you must configure the required environment variables. These variables are used for database connection, authentication, and email services. 

DB_URL=your_database_url
DB_USER=your_database_username
DB_PASS=your_database_password
JWT_SECRET=your_jwt_secret_key
MAIL_USERNAME=your_email_address
MAIL_PASSWORD=your_email_password

How to Set Environment Variables

For Windows (Command Prompt):

set DB_URL=your_value
set DB_USER=your_value
set DB_PASS=your_value
set JWT_SECRET=your_value
set MAIL_USERNAME=your_value
set MAIL_PASSWORD=your_value

For Windows (PowerShell):

$env:DB_URL="your_value"
$env:DB_USER="your_value"
$env:DB_PASS="your_value"
$env:JWT_SECRET="your_value"
$env:MAIL_USERNAME="your_value"
$env:MAIL_PASSWORD="your_value"

For Linux / Mac:

export DB_URL=your_value
export DB_USER=your_value
export DB_PASS=your_value
export JWT_SECRET=your_value
export MAIL_USERNAME=your_value
export MAIL_PASSWORD=your_value

Note: Ensure all environment variables are properly set before starting the backend. Missing variables may prevent the application from running.

6. Frontend Setup (Angular Build)

Option 1 (Recommended):

cd frontend
npm install -g serve
serve .

Then open:

http://localhost:3000

Option 2:

Open index.html directly in browser

7. Important Notes

  • Start backend before frontend
  • Ensure API URLs are correctly configured
  • Database should be pre-configured
